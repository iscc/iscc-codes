ISCC - Resources¶

The open-source software, live demos, publications, and organizations that make up the ISCC ecosystem. Everything below builds on ISO 24138:2024, the International Standard Content Code.

Open-source ecosystem¶

Every repository below is developed in the open under the Apache-2.0 license.

Core components¶

iscc-coreStable Authoritative ISO 24138:2024 reference implementation. The low-level codec and fingerprinting algorithms that every ISCC build rests on. View on GitHub → iscc-sdkStable High-level Python toolkit adding media-type detection, metadata extraction, and content processing. The primary integration entry point. View on GitHub → iscc-schemaStable JSON Schema, JSON-LD contexts, and Pydantic models for ISCC metadata interoperability. View on GitHub → iscc-libBeta High-performance polyglot implementation of the ISO 24138:2024 core algorithms. A Rust core with bindings for Python, Java, Go, Node.js, WASM, and more, conformance-tested against iscc-core. View on GitHub → iscc-cryptoBeta Ed25519 signing, W3C Verifiable Credentials, and cryptographic verification for signed ISCC declarations. View on GitHub → iscc-sumBeta Fast single-pass CLI for Data-Code and Instance-Code generation in Rust with Python bindings, from the BioCodes project. View on GitHub →

Discovery infrastructure¶

iscc-webStable REST API service for ISCC generation. Powers the public web demo at demo.iscc.io. View on GitHub → iscc-hubBeta Reference timestamping and declaration service. Issues ISCC-IDs with cryptographic receipts for public content declaration and discovery. View on GitHub → iscc-searchBeta Specialized multi-index similarity search with sub-millisecond retrieval for ISCC codes and SIMPRINTs. View on GitHub →

ISCC Semantic Codes¶

iscc-sctBeta Semantic Text-Codes built on deep learning. Generates SIMPRINTs for granular text matching across languages. A core pilot component. View on GitHub → iscc-sciBeta Semantic Image-Codes for visual content fingerprinting and similarity detection. View on GitHub →

Specifications & quality assurance¶

iscc-iepsDraft ISCC Enhancement Proposals documenting new features and algorithms that inform future ISO standardization. View on GitHub → twinspectStable Benchmarking framework for near-duplicate matching and similarity search across text, audio, image, and video content. View on GitHub →

Selected publications & coverage¶

A curated selection from the wider body of work that references the ISCC. Dates are given as published.

Standards¶

  • ISO 24138:2024 - International Standard Content Code - ISO/TC 46/SC 9, 2024. The normative definition of the ISCC. iso.org
  • C2PA Technical Specification - Coalition for Content Provenance and Authenticity, 2025. Adopts the ISCC as a soft-binding mechanism that links provenance data to content even after metadata is stripped. spec.c2pa.org

Reviews & standards landscape¶

  • Technical Report on AI and Multimedia Authenticity Standards - IEC, ISO & ITU (AMAS / World Standards Cooperation), 2025. Maps more than 30 standards for AI-era media and dedicates a section to the ISCC as an asset identifier. PDF
  • Mapping of EU Databases and Metadata Standards for Copyright-Protected Works - EUIPO, 2026. Highlights the ISCC and the ISCC Discovery Protocol as a reference architecture for federated content discovery. euipo.europa.eu
  • Introducing the Newest ISO Identifier Standard - Todd A. Carpenter, NISO, 2024. Introduces ISO 24138 to the information-standards community as a shift toward content-derived identifiers. niso.org
  • A Successful Start to a New Festival of Identifiers: PIDfest 2024 - Meadows, Jones & Carpenter, The Scholarly Kitchen, 2024. Positions the ISCC as a flagship intrinsic identifier alongside ISBN, DOI, and ISSN. scholarlykitchen.sspnet.org

Research & academic¶

  • EU AI-Act: Tagging GenAI Content - Heeger, Berchtold, Bugert & Steinebach (Fraunhofer SIT / ATHENE), Electronic Imaging, 2025. Selects the ISCC as the robust hashing primitive for an EU AI Act compliance infrastructure. DOI
  • ISCC: Neue Perspektiven für die KI-gesteuerte Identifikation von Inhalten - Titusz Pan, Information - Wissenschaft & Praxis (iwp), 2024. Academic exposition of the ISCC and its semantic text-code extension. DOI
  • Why Libraries, Archives and Museums Should Use the ISCC - Heller & Gragert (TIB / SBB), 2024. An advocacy piece for adoption across the GLAM sector. blog.tib.eu

Adoption & press¶

  • CommonsDB surpasses one million declarations - Doug McCarthy, Open Future, 2026. Each declaration binds to its file through a content-derived ISCC. commonsdb.org
  • Frankfurt Book Fair 2025: Identity Stamps - Ed Nawotka, Publishers Weekly, 2025. Describes the ISCC as an ISO-certified digital fingerprint powering content registries for AI licensing. publishersweekly.com
  • Bookwire Offers 'Protection' From Wrongful AI Usage - Porter Anderson, Publishing Perspectives, 2024. Reports ISCC codes generated for every product in Bookwire OS, including TDM opt-out notices. publishingperspectives.com

Talks & presentations¶

  • The ISCC Discovery Protocol - Titusz Pan, F1000Research slides, 2025. Decentralized signing, timestamping, and discovery for the ISCC. DOI
  • International Standard Content Code (ISCC) ISO 24138:2024 - Titusz Pan, EDItEUR Supply Chain Conference, 2024. The standard for the publishing supply chain. PDF
  • Similarity hashing for digital content identification in decentralized environments - Blockchain for Science Conference, Berlin, 2019. A 30-minute talk. Recording

Organizations & standards¶

ISCC Foundation¶

The ISCC Foundation is an independent international nonprofit organization that promotes information technologies for the common good. It supports the ISCC and the development and adoption of open standards and open-source technologies that help individuals and organizations create, manage, discover, access, share, and monetize digital content, knowledge, and ideas.

ISO - International Organization for Standardization¶

ISO/TC 46/SC 9 (Identification and description) standardized the International Standard Content Code as ISO 24138:2024.
